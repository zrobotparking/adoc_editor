語法,說明,範例
比例分配,"[cols=""1,2,3""]",三欄，寬度比為 1:2:3。
固定寬度,"[cols=""20%,80%""]",指定百分比寬度。
重複欄位,"[cols=""3*""]",快速產生三欄等寬的欄位。

2. 合併儲存格 (Spanning)
這是你之前問到的重點。語法結構是：[欄跨度].[列跨度]+。

A. 水平合併 (Column Span)
語法：n+（n 為欄數）

範例：|2+| 這格橫跨兩欄

B. 垂直合併 (Row Span)
語法：.n+（n 為列數）

範例：|.3+| 這格向下合併三列

C. 同時合併 (Both)
語法：m.n+

範例：|2.2+| 這格同時橫跨 2 欄與 2 列

3. 對齊操作 (Alignment)
對齊符號可以單獨使用，也可以跟合併語法組合。

水平對齊 (Horizontal)
<|：靠左（預設）

>|：靠右

^|：置中

垂直對齊 (Vertical)
.<|：靠上（預設）

.>|：靠下

.^|：垂直置中

組合範例：2.3+^.^| 代表：橫跨 2 欄、3 列，且文字在正中央（水平與垂直皆置中）。

4. 儲存格內容格式 (Styles)
你可以指定儲存格內的文字如何被解析。這通常放在對齊符號之前。

s| (Strong)：內容自動加粗。

m| (Monospace)：內容使用等寬字體（適合放 RISC-V 指令，如 csrr）。

a| (AsciiDoc)：這最重要！它允許你在儲存格內使用 AsciiDoc 語法（如清單、第二層表格、警告區塊等）。

l| (Literal)：保留空格與換行。

範例：

AsciiDoc

| m| csrrs rd, mcycle, x0  // 這一格會自動變成等寬字體
| a|                      // 這一格允許放入複雜內容
* 第一點
* 第二點
