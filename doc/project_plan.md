1. 專案願景
本專案旨在打造一個「跨平台、專業級」的技術文件表格編輯器。透過視覺化介面，讓使用者無需記憶複雜的 AsciiDoc (.adoc) 與 Markdown (.md) 表格語法，即可輕鬆完成「跨行跨欄」與「複雜內容嵌入」等專業排版。

2. 介面與外觀描述 (The Interface)
本工具在設計上仿效專業 IDE 排版，確保使用者能一眼掌握全專案狀態。

2.1 佈局規劃
左側：專案資源列 (Project Explorer)

顯示整個專案的資料夾結構。

自動識別 .adoc 與 .md 檔案，並能快速開啟。

中間：程式碼大腦 (Source Editor)

基於文字的原始碼編輯區（支援語法高亮）。

提供與右側預覽區的「同步捲動」功能。

右側：雙模式預覽/編輯區 (Visual Editor & Previewer)

預覽模式： 根據選定的渲染引擎顯示最終樣式。

編輯模式： 點擊「Edit Table」後進入類 Excel 的網格系統，支援點擊編輯。

3. 核心功能需求 (Key Functions)
A. 視覺化表格魔法 (Visual Table Editing)
直覺合併： 透過滑鼠選取多個儲存格後，一鍵執行橫向 (Colspan) 或縱向 (Rowspan) 合併。

複雜內容支援 (AsciiDoc a| 樣式)： 允許儲存格內包含多段落、清單或代碼塊，編輯器自動轉譯語法。

版本引擎切換： 可自由選取不同版本的 Asciidoctor 渲染引擎（如 2.0.x），解決版本不相容問題。

B. 大型專案支援 (Large-Scale Project Support)
變數感應 (Attributes Resolver)： 自動掃描全專案的 .adoc 變數定義，預覽時能正確顯示 {version} 等動態內容。

檔案連結解析 (Include Support)： 支援 include:: 指令。編輯時能自動偵測表格來自哪個子檔案，並在保存時正確寫回該檔案。

路徑追蹤： 自動讀取 :imagesdir: 等路徑設定，確保表格內的圖片不會破圖。

C. 歷史與同步 (Sync & History)
全局 Undo/Redo： 不論是左側改字或右側拉表格，皆共用同一個撤銷歷史紀錄。

雙向即時保存： 視覺區修改後按「Apply」，系統自動轉譯出最簡潔的語法並寫入原始碼。

4. 進階功能 (Good to Have)
智慧偵測與修正 (Smart Fix)
混亂代碼修復： 當用戶貼上排版混亂、縮排不齊的原始表格代碼時，工具能自動偵測邏輯並重新對齊。

欄位衝突預警： 若手寫語法中的欄位數量不一致，編輯器會以紅色高亮錯誤區塊，並提供「自動補齊」或「修復建議」。

5. 系統架構：核心與平台分離 (Headless Architecture)
為了實現「一份代碼，多端運作」，系統分為三層：

大腦核心 (Core Logic)： 負責解析語法、計算表格坐標、管理 Undo/Redo。此層不帶 UI，純 TS 撰寫。

共用組件 (Shared UI)： 負責表格的渲染長相與按鈕互動，VS Code 與網頁版共用。

平台適配層 (Platform Adapters)：

網頁外殼： 處理瀏覽器下載、localStorage。

VS Code 外殼： 處理與 VS Code 主進程的通訊、存取本地磁碟檔案。

6. 使用者流程 (User Journey)
開啟專案： 載入含有數百個 .adoc 的大型專案，工具自動解析全域變數。

搜尋定位： 在右側預覽看到某個崩壞的表格，點擊 [Edit Table]。

(選用) 智慧修復： 若表格語法原本有誤，點擊 [Smart Fix] 自動導正。

視覺編輯： 框選合併、輸入內容。

完成退出： 點擊 [Apply]，變動自動同步至子檔案，專案渲染維持正常。
